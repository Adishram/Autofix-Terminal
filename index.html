AutoFix Terminal

An auto-fixing developer tool that wraps your command execution in a pseudo-terminal. When a command fails, it automatically captures the error, locates the failing source code, and uses a local Large Language Model to attempt to fix the error for you.

Download for macOS

Features

  • Seamless Terminal Experience: Built with Tauri and xterm.js, providing a familiar terminal interface that inherits your system environment and shell configurations.
  • Automatic Error Detection: Parses standard error output to detect syntax and runtime errors in multiple languages including Python, Rust, C/C++, TypeScript, Javascript, Java, and Go.
  • Local LLM Integration: Uses litellm and Ollama to generate code fixes locally, keeping your code private and avoiding external API costs.
  • Infinite Auto-Fix Loop: The terminal will keep trying to fix the error in a loop until it succeeds. You can stop it manually at any time using Ctrl+C, which instantly restores the original file from a backup.
  • Live Status Indicator: The GUI displays the real-time connection status of your local LLM.

Prerequisites

  • macOS operating system.
  • Ollama installed and running locally on port 11434.

Usage

Run any command using the autofix CLI wrapper. For example:

autofix python3 script.py

If the script fails, AutoFix Terminal will intercept the failure and attempt to resolve it automatically.
